
# 📘 Assignment: Games in Python

## 🎯 Objective

Build a classic Hangman word-guessing game using Python, practicing string manipulation, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Hangman game where players guess letters one at a time to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list using the `random` module
- Display current progress with underscores and correctly guessed letters (e.g., `_ _ a _ _`)
- Accept a single letter as input from the player each turn
- Track and display the number of incorrect guesses remaining
- End the game when the word is fully guessed or the player runs out of attempts
- Display an encouraging win message or a friendly lose message with the correct word
